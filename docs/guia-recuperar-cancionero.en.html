Recover the Songbook on a new WordPress

Seven steps to move songs, scores, audio, services and team to a new site. You do not need the rest of the WordPress site.

  1. 1

    Download a backup

    Current site
    • Songbook
    • Your account menu
    • Backups
    • Download backup

    Leave all four options checked: songs, scores and audio, services, and settings.

    It downloads cancionero-copia-YYYY-MM-DD.zip (about 13 MB).
  2. 2

    Install the plugin

    New WordPress
    • Plugins
    • Add New
    • Upload Plugin

    Choose the plugin file, click Install Now and then Activate.

    dist\pieb-cancionero-<version>.zip
    In the plugin list, Cancionero appears as active, with the latest version.
  3. 3

    Turn on permalinks

    WordPress nuevo
    • Settings
    • Permalinks

    Choose Post name and click Save Changes. This keeps the addresses clean.

  4. 4

    Create the songbook page

    WordPress nuevo
    • Pages
    • Add New
    • Title: Songbook
    • Add a Shortcode block (its icon is [/]) and type inside it:
    [cancionero]

    Click Publish.

    Do not use the Code or Preformatted block: they show [cancionero] as text in a gray box. If that happens, delete that block and type [cancionero] in a normal paragraph: that works too.

    When you open the page you see the empty songbook, with its menu on the left.
  5. 5

    Restore the backup

    WordPress nuevo
    • Songbook page
    • Your account menu
    • Backups
    • Restore from a backup
    • Choose the .zip from step 1. Everything shows up as New.
    • Click Restore 48 songs, 3 services, the settings and confirm.
    • Wait for the log to finish: the scores are uploaded one by one.
    You see “Backup restored”. Click View the restored songbook and your songs and services appear.

    Do this while signed in as an administrator: only administrators see “Backups”.

  6. 6

    Set up email

    WordPress nuevo

    Without this, the sign-in links do not arrive. Install the FluentSMTP plugin and create an Other SMTP connection:

    Server
    smtp.gmail.com
    Port
    587
    Encryption
    TLS
    Username
    the group’s Gmail account
    Password
    its app password
    • Songbook
    • Settings and team
    • Send me a test email
    The test email arrives. The team list already comes in the backup: each person signs in with their link and their account is created automatically.
  7. 7

    Choose the look

    WordPress nuevo
    • Settings and team
    • Default theme

    “Like the site” takes its color from the WordPress theme you have installed, so the navy blue from before may not appear. If you do not like it, choose Pulse or any other.

Does something not look like this?

Note which step you were on and what message appeared. The restore log (step 5) says exactly which song or service failed and why.
